# DuloClan-Documentation

Documentation for the UGUI scripts shared by the DuloGames UI assets (namespace `DuloGames.UI`).

New here? Start with **[Getting Started](getting_started/getting_started.md)**: requirements, the manager assets, input setup and canvas scaling.

### About Demo Scripts
The demo scripts in our assets are only meant for demonstration and will not be documented. You can still use them as a base for your own purposes.

### Availability
Not every asset ships every system. If a page describes a component you can't find in your project, your asset does not include that system.
